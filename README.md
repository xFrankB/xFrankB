## `principles`

- **Construir con intención:** cada proyecto debe responder a una necesidad concreta o demostrar una decisión técnica relevante.
- **Aprender haciendo:** prefiero validar conceptos mediante prototipos funcionales y pequeñas iteraciones públicas.
- **Comunicar el trabajo:** una solución técnica también debe poder explicarse con claridad a colaboradores, usuarios y reclutadores.
- **Mejorar continuamente:** documentación, revisión, pruebas y orden del código forman parte del resultado.
