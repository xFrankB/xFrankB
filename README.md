Aplicación full-stack organizada para crecer por módulos. El repositorio separa `client`, `server`, `shared` y `patches`, e incluye TypeScript, React, Vite, Express, Node.js y pnpm. GitHub identifica TypeScript como el lenguaje principal del repositorio, con 97% del código.
