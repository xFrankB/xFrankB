## `/ selected-work`

### [U3_APM](https://github.com/xFrankB/U3_APM)

**Aplicación full-stack organizada para crecer por módulos.** El repositorio separa `client`, `server`, `shared` y `patches`, e incluye una base de desarrollo y construcción con TypeScript, React, Vite, Express y pnpm.

```text
U3_APM/
├── client/       interfaz y experiencia de usuario
├── server/       lógica del servidor
├── shared/       código compartido
├── patches/      ajustes de dependencias
├── package.json  scripts y dependencias
└── vite.config.ts
```

## `/ principles`

- **Construir con intención.** Cada proyecto debe responder a una necesidad concreta o demostrar una decisión técnica relevante.
- **Aprender haciendo.** La teoría se vuelve útil cuando termina convertida en una implementación que puede revisarse.
- **Comunicar el trabajo.** Una solución técnica también debe poder explicarse con claridad.
- **Mejorar continuamente.** Documentación, orden del código y revisión forman parte del resultado.
